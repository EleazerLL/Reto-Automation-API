# Reto de Automatización: API Testing con Karate

Este proyecto contiene la automatización de servicios REST utilizando el framework Karate.

## 🚀 Alcance
- **API Target:** [GoRest](https://gorest.co.in/)
- **Operaciones:** Validación de flujos CRUD (Creación, Lectura, Actualización y Eliminación de usuarios).
- **Validaciones:** Verificación de status codes, esquemas JSON y tiempos de respuesta.

## 🛠️ Requisitos
- Java 17
- Maven

## 🏃 Ejecución
Para correr los tests de API, ejecuta el siguiente comando en la raíz:
```bash
mvn test
